# Competencias técnicas

Mi experiencia abarca el desarrollo backend, la ingeniería de datos y la aplicación de modelos de inteligencia artificial.

## :material-api: Desarrollo backend

**Python**, **FastAPI** y **Pydantic**. Diseño de APIs REST, validación de datos, autenticación y documentación con OpenAPI. Pruebas, control de versiones con **Git** y buenas prácticas de desarrollo.

## :material-robot-outline: Inteligencia artificial generativa

Arquitecturas **RAG**, evaluación con **LLM-as-a-judge**, prompt engineering y fine-tuning ligero. Integración de modelos de **OpenAI**, **Azure OpenAI** y modelos de código abierto.

## :material-brain: Machine learning y NLP

Deep learning con **PyTorch**, procesamiento del lenguaje natural y reconocimiento de entidades con **spaCy** y **Hugging Face**. Experiencia en forecasting, análisis de texto y aplicaciones de aprendizaje automático en salud.

## :material-database-arrow-right: Datos y automatización

Pipelines de datos y procesos ETL/ELT con Python, **Airflow** y **Prefect**. Automatización con **n8n** e integración entre APIs. Visualización y dashboards interactivos con **Streamlit**.

## :material-spider-web: Extracción de datos

Web scraping con **BeautifulSoup**, **Playwright** y **Scrapy**. Paginación, limpieza, deduplicación y estructuración de datos para su análisis.
